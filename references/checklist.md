# 速查清单（一页纸）

> 做新课件网页时，把这一页放在旁边。完整解释见 `方法手册.md`。

## A. 开工 10 分钟

- [ ] 范围：整门课 / 一章 / 一个题型？
- [ ] 输出：总复习页 / 专题页 / 题库 / 一页速查？
- [ ] 资料：PPT 页码、图片页、公式页、例题页都找到了吗？
- [ ] 验收：能复述？能做例题？手机能看？能打印？
- [ ] 约定：矩阵用行向量还是列向量？Softmax 按行还是按列？题目有没有 `1/√d`？

## B. 内容拆解

- [ ] 章 → 节 → 知识点三级编号。
- [ ] 每个知识点有：结论、为什么、怎么做、例子、易错、来源页码。
- [ ] 学习要求：掌握 / 理解 / 了解。
- [ ] 考点：高频 / 易错 / 计算题 / 对比题。
- [ ] 公式/矩阵维数写清楚。
- [ ] 不编造；不确定标 `[待核对]`。

## C. 页面结构

- [ ] 顶栏 + 三级目录（章/节/知识点）。
- [ ] 章首：目标 + 一句话导语。
- [ ] 每个知识点一张卡。
- [ ] 章末：考点速览。
- [ ] 专题页：题目 → 约定 → 4 步 → 考场模板 → 易错 → 答案。
- [ ] 页脚：来源、更新日期、返回入口。

## D. UI

- [ ] 设计变量统一（颜色/圆角/阴影/间距）。
- [ ] 正文 15–16px，行高 1.75–1.8。
- [ ] 矩阵/公式用等宽数字。
- [ ] 表格外层 `overflow-x:auto`。
- [ ] 卡片层级 ≤3 层。
- [ ] 深色模式单独检查。
- [ ] 320/360/390 不横向溢出。

## E. 动画

- [ ] 每个动画都在解释顺序/因果/定位/对比/状态之一。
- [ ] 默认不自动播放。
- [ ] 有上一步/下一步/重置/静态总览。
- [ ] 切 tab/步骤先清定时器。
- [ ] 减少动画模式可用。
- [ ] 动画结束态文字可独立读懂。

## F. 交互

- [ ] 可点元素有 hover/focus/选中态。
- [ ] 矩阵格子点击 → 显示来源/算式。
- [ ] 目录：只展开当前路径；移动端点完关闭。
- [ ] 折叠：`aria-expanded` 同步。
- [ ] 复制/打印可用。
- [ ] 键盘 Tab/Enter/方向键可用。

## G. 发布前质检

- [ ] 控制台 0 报错，网络 0 404。
- [ ] `scrollWidth == clientWidth`（320/360/390/768/1024/1440）。
- [ ] 图表/矩阵/表格/按钮无裁切重叠。
- [ ] 所有内部链接、跨页链接可打开。
- [ ] 无外部字体/CDN/图片依赖。
- [ ] 深色、减少动画、无 JS 回退。
- [ ] 手机 4G/5G 打开一次。
- [ ] 首页 `index.html`、favicon、meta 描述。

## H. 常见致命 bug

- [ ] 图表没被塞进 `.case-h/.box-h/.tbl-title/<p>`。
- [ ] 动画没有选中页头小图标（`.demo-stage svg`）。
- [ ] SVG `<text>` 里没有 `<sub>/<sup>`。
- [ ] 目录知识点从 `.card.kp[id]` 生成，不是空 `h4[id]`。
- [ ] 内容高度变化后重算滚动监听。
- [ ] 深链接不被 smooth scroll 抢走。
- [ ] 最终步骤没有被 dim。
- [ ] 矩阵最后一列没有被裁切。
- [ ] 行列约定统一，没把 `KᵀQ` 和 `QKᵀ` 混用。
- [ ] 舍入说明写了，0.0001 差异不是错。

## I. 发布

- [ ] 本地：`python -m http.server 8787`
- [ ] 公网临时：`cloudflared tunnel --url http://127.0.0.1:8787`
- [ ] 长期：Cloudflare Pages / Vercel / GitHub Pages / 自有服务器
- [ ] 发布后：手机打开、主/专互跳、刷新可用、分享预览正常。

---

**记住**：先有内容结构，再有视觉；先有「为什么」，再有「怎么算」；先能验收，再谈好看。
