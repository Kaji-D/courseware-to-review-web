# AI 生成提示词（可复用）

> 用法：按顺序把提示词发给 AI；每一步都要求它先输出结构/清单，再写代码。  
> 把 `{{...}}` 替换成你的资料信息。

---

## 0. 角色与总约束

```text
你是课程内容编辑 + 前端工程师。任务：把课件整理成单文件交互式复习网页。
硬约束：
1. 单文件 HTML，CSS/JS/SVG 全内联，零外部依赖，离线可用。
2. 不做纯装饰动画；每个动画必须解释顺序/因果/定位/对比/状态之一。
3. 手机 320px 宽可用，桌面 1440px 好看；不允许页面级横向滚动。
4. 深色模式、减少动画模式、无 JS 回退都要可用。
5. 公式/矩阵维数必须正确；不确定的内容标 [待核对]，不要编造。
6. 先给信息架构和组件清单，确认后再写代码。
```

---

## 1. 提取与拆解

```text
请阅读以下课件内容（PPT 页码：{{页码范围}}），输出 Markdown 表格：
章 | 节 | 知识点 | 学习要求(掌握/理解/了解) | 一句话结论 | 为什么 | 怎么做/公式 | 例子 | 易错点 | 来源页码

要求：
- 纯图片页：先描述图片内容，再拆解，不要跳过。
- 公式用 Unicode/LaTeX 写清楚；矩阵标明维数。
- 按“章 → 节 → 知识点”三级编号（如 k3-2-1）。
- 每个知识点至少有一个例子或一个易错点。
- 不确定的标 [待核对]。
```

---

## 2. 信息架构

```text
基于上面的拆解，给出页面信息架构：
1. 页面形态（总复习 / 专题 / 题库 / 速查）。
2. 顶部栏、目录、章首、知识点卡、图表、章末考点、页脚的结构。
3. 哪些内容用表格、哪些用折叠、哪些用动画、哪些用交互。
4. 移动端如何折叠/堆叠。
5. 预估页面长度和组件数量。
不要写代码，先给结构。
```

---

## 3. UI 设计

```text
请为这个页面设计一套 UI 变量和组件规范：
- 颜色：背景/表面/文字/边框/主色/考试重点/正确/错误；浅色+深色。
- 字体：中文系统字体 + 等宽数字。
- 间距、圆角、阴影、卡片层级。
- 组件：章首、KP 卡、表格、公式、流程步骤、折叠、图示、演示、矩阵、考点速览。
- 断点：1200/1120/940/760/640/480/360。
输出 CSS 变量和关键组件样式，不要写完整页面。
```

---

## 4. 动画/交互方案

```text
请为每个需要动画的知识点设计交互：
- 动画目的（顺序/因果/定位/对比/状态）。
- 触发方式（点击/自动/滚动）。
- 状态（step、total、mode、static、timer）。
- 控件（播放/暂停/上一步/下一步/重置/静态总览）。
- 静态总览展示什么。
- 减少动画模式如何降级。
输出表格，不要写代码。
```

---

## 5. 生成单文件页面

```text
请按已确认的结构生成单文件 HTML：
- 顶部固定栏 + 侧边三级目录；移动端抽屉。
- 章首目标、KP 卡、表格、公式、图示、章末考点。
- 步骤/tab/播放器/矩阵格子点击按需加入。
- 内联 SVG；CSS Grid 矩阵；事件委托。
- 深色、减少动画、无 JS 回退。
- 不要引用任何外部字体/CDN/图片。
- 代码加注释，变量用语义命名。
先输出完整 HTML，再输出一个“如何改内容”的 10 行说明。
```

---

## 6. 考试型专题页

```text
请把这道题做成 4 步交互专题页：
题目（条件+分值）→ 先记约定 → 分步计算（为什么/怎么做）→ 考场模板 → 易错点 → 标准答案。

要求：
- 每一步有“为什么这样算”的解释，不只给公式。
- 矩阵用 CSS Grid 渲染，格子可点击显示来源/算式。
- 显示维度链（如 3×4 → 4×4 → 3×4）。
- 按列/按行 Softmax 要明确说明。
- 给出评分点、检查清单、可复制的 7 行答卷。
- 最后注明舍入差异（如 0.8251 vs 0.8252）。
```

---

## 7. 质检

```text
请对这份 HTML 做发布前质检，逐项输出“通过/不通过 + 证据”：
1. 控制台错误、404、外部依赖。
2. 320/360/390/768/1024/1440 是否横向溢出。
3. 图表/矩阵/表格/按钮是否裁切或重叠。
4. 目录/步骤/折叠/播放/复制/打印/跨页链接是否可用。
5. 深色、减少动画、无 JS 回退。
6. 公式/矩阵维数/行列约定/舍入是否正确。
7. 可访问性：Tab、focus、aria、对比度。
不要只说“看起来没问题”，要给选择器、数值或截图证据。
```

---

## 8. 发布

```text
请把这份单文件网页整理成静态站点：
- 目录结构：index.html + 资源（如有）+ favicon + meta。
- 本地预览命令。
- 公网临时地址（Cloudflare Tunnel）命令。
- 长期部署选项（Cloudflare Pages/Vercel/GitHub Pages）和需要用户提供的信息。
- 发布后回归清单（手机、主/专互跳、刷新、分享预览）。
```

---

## 9. 让 AI 记住这套方法

```text
请把这次整理的流程、组件、动画模式、常见 bug、质检清单写成一份可复用方法手册，
并抽成一个本地 skill：
- 触发词：把 PPT/课件整理成复习网页、交互式学习网页、考试型专题页。
- 工作流：提取 → 拆解 → 信息架构 → UI → 动画/交互 → 质检 → 发布。
- 必须附带：模板、检查清单、常见坑。
- 下一次遇到同类任务时，直接按这套流程执行。
```
